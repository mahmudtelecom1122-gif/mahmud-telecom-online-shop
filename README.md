# Mahmud Telecom Online Shop

আপনার বর্তমান Mahmud Telecom ওয়েবসাইটকে Online Shopping + Delivery + PostgreSQL backend হিসেবে চালানোর জন্য প্রস্তুত প্যাকেজ।

Start backend:
`cd server`
`npm install`
`npm start`

তারপর:
`http://localhost:3000`

Admin:
`http://localhost:3000/admin-login.html`
